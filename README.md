# stickyurl

Kleiner statischer URL-Router: mehrere Ziel-URLs angeben, Link erzeugen, beim ersten Aufruf zufälliges Ziel wählen und diese Auswahl im Browser speichern.

https://fischerscode.github.io/stickyurl/

Die Ziel-URLs liegen im `#`-Fragment, die Logik läuft vollständig clientseitig. Kein Backend, keine Datenbank, keine Abhängigkeiten.
