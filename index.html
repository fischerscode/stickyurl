stickyurl

Mehrere URLs rein, ein Link raus. Beim ersten Aufruf wird ein Ziel zufällig gewählt und im Browser gespeichert.

Wie es funktioniert

Die Ziel-URLs stecken im Fragment hinter #. Die Auswahl passiert lokal im Browser und wird in localStorage gespeichert. Derselbe Browser landet beim nächsten Aufruf desselben Links wieder beim selben Ziel.

Kein Backend, keine Accounts, keine Datenbank. Wird der Browser-Speicher gelöscht oder ein anderer Browser verwendet, wird neu gewählt.
