2. Funktionsweise dieser Website

Diese Website erzeugt Weiterleitungslinks, die mehrere vom Nutzer eingegebene Ziel-URLs enthalten. Die Ziel-URLs werden im Fragment-Teil der erzeugten Adresse hinter dem Zeichen # gespeichert. Die Verarbeitung des Fragments erfolgt im Browser.

Beim ersten Aufruf eines solchen Weiterleitungslinks wählt JavaScript im Browser zufällig eine der hinterlegten Ziel-URLs aus. Diese Auswahl wird im lokalen Browser-Speicher (localStorage) gespeichert, damit derselbe Browser bei einem erneuten Aufruf desselben Links wieder dasselbe Ziel verwendet.

3. Lokaler Speicher (localStorage)

Für die beschriebene Zuordnung wird localStorage verwendet. Die Information bleibt grundsätzlich auf dem jeweiligen Endgerät bzw. im jeweiligen Browser gespeichert, bis sie dort gelöscht wird. Die Website setzt für diese Funktion keine eigenen Tracking-Cookies ein.
